SF Capital Data Warehouse

A private, internal research-data tool operated by SF Capital.

What it is

SF Capital Data Warehouse is internal software that SF Capital uses to organise its own research data. It runs on SF Capital's private servers and keeps SF Capital's datasets, research archives and model files in SF Capital's own Google Drive.

How it uses Google

The application uses Google Sign-In (OAuth) with the Google Drive API so that SF Capital's private servers can list, read and write files in SF Capital's own Google Drive. It is used only by SF Capital's owner, with SF Capital's own Google account. It is not offered to the public, and it does not request access to anyone else's Google account.

Privacy
